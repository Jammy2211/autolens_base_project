# Core wiki — PyAuto\* reference

The reference layer for everything an agent needs to know about the PyAuto\* stack
when helping a user write lensing code. Skills in [`../../skills/`](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/skills) link in
here for the *what* / *which* / *why*.

## Stack

- [The stack at a glance](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/wiki/core/stack/overview.md) — dependency chain, who imports whom.
- [PyAutoNerves](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/wiki/core/stack/autonerves.md) — YAML config loader.
- [PyAutoArray](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/wiki/core/stack/autoarray.md) — arrays, grids, masks, geometry.
- [PyAutoFit](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/wiki/core/stack/autofit.md) — model composition, non-linear search, samples.
- [PyAutoGalaxy](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/wiki/core/stack/autogalaxy.md) — light + mass profiles, galaxies.
- [PyAutoLens](https://raw.githubusercontent.com/PyAutoLabs/autolens_assistant/main/wiki/core/stack/autolens.md) — tracer, ray tracing, lensing umbrella.
